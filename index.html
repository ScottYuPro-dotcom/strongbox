        Which apps open an AES-256 zip

        AES zip encryption is a WinZip extension, not part of the original zip spec. Most archivers handle it; the unzippers built into Windows and macOS do not, and give a vague error rather than asking for the password.

        7-ZipWinRARKekaThe Unarchiver PeaZipZArchiver · AndroidiZip · iOS p7zip · CLIWindows ExplorermacOS Archive Utility

        To decrypt from a terminal: 7z x strongbox.zip. This page's Unlock tab opens them too.

        Everything runs in your browser — files are read with the File API, zipped and encrypted in memory, and handed back as a download. There is no server and no upload, so hosting this page publicly exposes nothing but the page itself. Lose the passphrase and the archive is unrecoverable; there is no reset.
